知字输入法 · 测试版（Mac）
================================

【安装】
1. 把「知字」拖到右边的「应用程序」。
2. 打开「应用程序」里的「知字」。第一次打开会：
   · 把输入法装好（弹出提示框，点「好」）；
   · 告诉您这是测试版、已开启测试记录（见下面「测试记录」）。
3. 点屏幕右上角菜单栏的输入法图标，选「知字拼音」，就能用了。
   如果列表里没有「知字拼音」：
   · 到「系统设置 → 键盘 → 输入法（编辑）」，点「+」，在「简体中文」下添加「知字拼音」；
   · 还是没有，就「注销」再登录一次（苹果对全新输入法的首次发现有时要这一步）。

【用法要点】
· 正常打拼音，空格或数字键选字；按 = 把候选展开成四行。
· 菜单栏的输入法图标 → 「皮肤管理…」可以换候选框皮肤（有动画的、可预览）。
· 打错、候选里没有您要的词、候选框怪怪的、卡顿，都请截个图告诉我，并附上版本号：
  菜单栏输入法图标的菜单最下面一行写着「知字 · 版本 xxxx」。

【测试记录】
· 这是测试版，已默认开启记录（发给您的人已经跟您说过）：会记录您打字时的拼音、候选词、选了哪一个、光标前最近 8 个字（网址、邮箱、长串字母数字会先替换掉，密码框不记录）和电脑名称，每小时上传一次，只用来改进输入法。
· 随时可以在知字首页的「常用」里关掉「持续记录」，关掉后不再记录、不再上传。
· 想删掉已上传的内容，联系把这个包发给您的人。

【卸载】
点屏幕右上角菜单栏的「知字」图标 → 「卸载知字输入法…」，然后把「应用程序」里的知字拖进废纸篓；输入法列表里的条目在下次注销登录后消失。

这是测试版，可能有毛病；谢谢您帮忙试用。
