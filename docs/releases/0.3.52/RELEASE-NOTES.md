# 知字 0.3.52 for macOS

在管理台的「打字记录」页可勾选「加入用户体验改进计划」。默认关闭。勾选后会持续记录并每小时发送加入后产生的拼音、候选、上屏文字、选词、退格和耗时等信息，用于改善候选排序和拼音纠错。光标前的文字、应用标识及设备名称不会随上传发送。服务器保留最近 30 个自然日的计划记录。取消勾选会停止录制和后续上传，本机记录可以自行删除。

适用于 Apple Silicon、macOS 14 及以上。将「知字」拖入「应用程序」并打开，按提示升级。上一正式版为 0.3.50。

## English

The new User Experience Improvement Program is optional and off by default. Open the typing records page in the manager to join. While enabled, the app sends typing quality records collected after enrollment, including pinyin, candidates, committed text and correction metadata. Preceding text, application identifiers and device names are excluded from uploads. Program records are retained on the server for 30 calendar days. Uncheck the option to stop recording and uploading.

For Apple Silicon Macs running macOS 14 or later.
