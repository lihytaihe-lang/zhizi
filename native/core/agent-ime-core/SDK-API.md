# 知序 SDK 接口合同

规范以本包 `include/agent_ime_core.h` 及 Rust `sdk` 模块为准。组件0.3.1，ABI6。宿主负责系统输入框架、候选窗口、焦点、安全状态与推理实现。

| 场景 | 接口与职责 |
|---|---|
| 版本 | `aim_core_abi_version` 核对结构/键值 ABI；`aim_core_version` 借用静态版本串 |
| 生命周期 | `aim_session_create` 输入显式UTF-8目录和应用标识；空指针表示创建失败；`aim_session_destroy` 释放一次 |
| 输入/页面 | `aim_session_process`、`aim_session_current_page`；C函数返回码与输出的模型status分开；每份输出都由`aim_result_free`释放 |
| 编辑/宿主 | Text、移动、退格、翻页、选词、焦点、睡眠等键通过同一事件入口；修饰键和安全状态必须来自真实宿主 |
| 配置 | 模糊拼音、场景/标点、前文、词库重载等由会话接口配置；需尊重组字中保护或下一边界生效规则 |
| 词层 | 词库/上下文快照加载、应用和释放由对应API完成；读取失败不以空词典替代已有效内容 |
| 学习 | 普通选词需验证事件和保留窗口；撤回选择可调用`aim_session_withdraw_selection`；显式本地管理用`zhixu::learning::management_*` |
| 评分 | `aim_ranking_*`、上下文组信息及重排接口接入外部候选分数；文字/数组编码、数量和门槛以头文件为准 |
| 整句 | `aim_session_set_zhiju_vocab`加载词表；同步搜索、分步搜索和脱离会话的快照/搜索对象支持宿主推理调度 |
| 缓存 | 短进程最后一个键之后可调用`aim_index_cache_flush`，等待有界时间让后台词库缓存完成；失败不改变已完成输入 |

## 所有权与线程

应用标识应为1至128个UTF-8字节、无控制字符，推荐反域名形式；Rust入口检查此限制。

同一个会话只能串行使用，不能重入；所有输入缓冲在调用期间有效，不能保留回调借用的指针。C创建应串行且活动会话保持同一目录部署。Rust入口用部署租约执行该限制，并让每份输出变成独立拥有的字符串/向量。高级原始指针不转移会话所有权，不能自行销毁、跨线程使用或留到Engine释放后。

独立的整句快照和搜索对象可用于后台计算，不能在后台访问活动会话。回到会话拥有线程后按代次应用，输入改变后的旧结果不能覆盖当前页面。每种对象使用自己的销毁API；短缓冲重读、完成与错误码按头文件合同处理。

## 安全状态和输入事件

NonSecure=0、Secure=1、Unknown=2。未知状态不能猜成普通输入。焦点丢失/停用/睡眠等按真实生命周期发送；不要把未识别键映射为屏蔽操作：BlacklistCandidate=18、Unsupported=19。Shift/Control/Option/Command位与宿主映射保持一致。

事件编号用于验证和幂等。编号0可传入但不授权持久学习；对同一交付事件重试时复用编号，新的选择事件使用跨会话唯一编号。管理文件的修订在下一轮组字边界被观察，当前已显示的数字选择保持原合同。

## 外部评分与生成

核心不加载宿主推理框架、不建立网络连接。外部推理以回调或分步结果提供分数，所有分数必须有限，数量与原始候选/token布局完全一致。

`AimZhijuScorer` 输入为Int32的`rows × cols` token表，cols=40；包含BOS及截断后的上下文/生成字符，按词表规则补齐PAD。输出是Float32的`rows × vocab`下一字符对数概率；成功返回0，失败返回非零。不跨C ABI传播异常/panic，不保留借用指针，不在回调里重入会话。

原生搜索预算包含准备与同步推理耗时，不能中断已经运行中的同步回调；只会在下一步前检查截止时间并保留已完成结果。因此宿主也须限制单次推理时间。预算0不执行推理。实际候选应用仍遵守核心的完整读音、相对评分、代次和候选页保护规则。

## 数据和发行

词库目录只放受信任、具有分发许可的词表；个人目录由当前用户控制并保持私有权限。学习JSON备份会包含个人词、应用偏好和选择记录。导入先预览，容量/格式不合格时拒绝，不用整文件回滚覆盖并发新学习。回退旧核心前保存学习备份，因为旧容量估算可能较早淘汰记录。

模型、系统输入法、皮肤交易及公有仓库上传具有独立的交付状态。SDK的本地编译、示例与公开测试不代替这些阶段的真实验收。

独立公开测试还提供一个均匀对数概率回调：验证真实核心发出40列token、预算0不调用回调、正常搜索能完成且不改页面。它演示接口合同，不代表神经模型质量。
