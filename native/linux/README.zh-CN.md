# 知字 Ubuntu / IBus

当前支持的验收目标为Ubuntu24.04 amd64、GNOME Xorg、IBus1.5。其他桌面、Wayland和Fcitx支持以各自实测记录为准。

安装：`sudo apt install ./ibus-zhizi_0.3.46_amd64.deb`。首次安装后注销并重新登录，在系统“设置→键盘→输入源”添加中文“知字”，再切换到知字。升级沿用该输入源。

全拼、简拼、字母与数字按核心输入规则处理；空格或数字选择，鼠标可点候选，减号/等号及PageUp/PageDown翻页，方向键移动候选或光标，Esc取消。单独按Shift切换中英文。Ctrl+Backspace删除当前学习候选；Ctrl+Shift+Backspace永久屏蔽当前候选。

应用列表的“知字设置与个人词”及输入法菜单可打开中文设置。候选排序、知句生成和键位纠错独立控制；下次切换输入窗口时生效。当前学习可查看、删除、撤销上次删除（30分钟）、备份导出和预览合并导入；“永久屏蔽”页可解除屏蔽。备份包含学习词和选择事实，请妥善保存。导入重复事实取较大计数，超过容量或格式无效时不改现有学习。

词库与固定模型安装于`/usr/share/zhizi`，程序和运行库在`/usr/lib/zhizi`。个人数据在`$XDG_DATA_HOME/zhizi`（默认`~/.local/share/zhizi`），当前学习为其`Rime/agent_zhixu_learning_v1.json`，删除撤销在私有目录`.learning-undo-v1`。全程本地运行，不配置测试记录或上传。密码、PIN和带隐私提示的输入框原样输入，并清空上下文与待用模型结果。

缺模型或模型校验失败时继续基础输入；知句存在时限和生成质量边界，不保证每次生成都能作为首选。界面候选与数字、鼠标选择都来自同一核心页；晚到模型结果由IBus界面事件取回并显示后再处理下一次选择。

卸载：`sudo apt remove ibus-zhizi`。卸载程序保留个人学习和设置；重新安装可继续使用。回退时安装保留的旧deb，先在设置中导出学习备份。不要手工覆盖或删除个人数据目录来“修复”输入。此Ubuntu首版的升级/回退实际覆盖范围以交付记录为准；开发候选包与正式包会分别保留源码和哈希，不把其他平台安装包当作Linux回退包。

本阶段使用IBus原生候选窗口。整体计划中的完整皮肤管理、商店与购买在Ubuntu验收后继续实施。
